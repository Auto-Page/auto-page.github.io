Supporting services:
- Cloud Logging / Monitoring: logs, metrics, alerts
- Redis / Memorystore: cache, rate limits, short-lived state

Data flow summary:
1. User opens the web app.
2. User signs in through the identity provider.
3. API stores mission/workspace state in Postgres.
4. API sends orchestration jobs to the queue.
5. AI orchestrator worker calls the LLM and generates reports.
6. Artifacts go to Cloud Storage and status updates go back to the API.
7. Logs and alerts are collected centrally.
