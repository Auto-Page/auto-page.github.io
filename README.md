## Introduction
Auto-Page is a community that based on the maillist, where we share the new ideas weekly for building micro-saas, AI applications business for entrepreneurs and developers.
### Maillist
You can subscribe to our maillist to receive the latest ideas and updates directly in your inbox.
### Website
You can also visit our website to explore the ideas and resources we share.
### Community
Join our community to connect with like-minded individuals, share your thoughts, and comment on the others' ideas.

## Tech Stack for this page
- Next.js
- Tailwind CSS
- GitHub Pages
- Dev Container
- GitHub Actions

## Development on Local
1. Build command: `npm run build`
2. Development command: `npm run dev`

## Deployment
1. GitHub Actions will automatically deploy the page to GitHub Pages when you push the code to the main branch.
2. You can also manually deploy the page by running the following command: `npm run deploy`
