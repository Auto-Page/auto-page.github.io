# Design Skill

## Purpose
Use this skill for product messaging, information framing, visual direction, and user experience clarity.

## Responsibilities
- Shape the narrative and presentation of the product.
- Improve clarity of user-facing screens and copy.
- Define visual direction and content hierarchy.
- Make the experience feel credible and easy to follow.

## Input Types
- Product scope
- Landing page copy
- User flow descriptions
- Brand direction
- Feedback on clarity or confusion

## Output Format
- Messaging recommendations
- UX framing suggestions
- Content hierarchy
- Visual direction notes
- Copy improvements

## Quality Bar
- Prioritize clarity over decoration.
- Keep the user journey easy to understand.
- Make the product feel trustworthy and intentional.
- Ensure outputs fit the target audience.
