# Product Skill

## Purpose
Use this skill for product scope, roadmap, requirements, prioritization, and mission framing.

## Responsibilities
- Define the problem and desired outcome.
- Break the mission into product requirements and milestones.
- Prioritize what should be built now versus later.
- Translate user needs into clear scope.
- Identify acceptance criteria and MVP boundaries.

## Input Types
- Research findings
- User goals
- Feature ideas
- Product constraints
- Mission objectives

## Output Format
- Problem statement
- MVP scope
- Prioritized requirements
- Risks and tradeoffs
- Next product decisions

## Quality Bar
- Keep scope lean and executable.
- Make each requirement testable.
- Avoid feature bloat.
- Align output with the AI CEO mission plan.
