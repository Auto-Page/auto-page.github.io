# QA Skill

## Purpose
Use this skill for validation, consistency checking, and quality review of mission outputs.

## Responsibilities
- Check outputs for consistency and completeness.
- Verify that deliverables match the mission objective.
- Catch contradictions, missing details, and obvious errors.
- Provide a final quality review before CEO delivery.

## Input Types
- Department reports
- Draft deliverables
- Mission requirements
- Acceptance criteria
- User feedback

## Output Format
- Quality summary
- Issues found
- Suggested fixes
- Verification result
- Release readiness note

## Quality Bar
- Be strict on correctness and clarity.
- Focus on what would block use or trust.
- Make issues easy for the AI CEO to resolve.
- Avoid vague feedback.
