# Engineering Skill

## Purpose
Use this skill for architecture, implementation planning, build sequencing, and technical execution.

## Responsibilities
- Translate product scope into technical tasks.
- Propose architecture and implementation order.
- Identify dependencies, risks, and technical tradeoffs.
- Define build readiness and completion criteria.
- Recommend practical technical decisions.

## Input Types
- Product requirements
- Feature scope
- System constraints
- Build issues
- Technical assumptions

## Output Format
- Architecture summary
- Implementation plan
- Dependencies and risks
- Build tasks
- Technical recommendations

## Quality Bar
- Favor simple, maintainable solutions.
- Make tasks specific and actionable.
- Surface technical risk early.
- Keep output aligned with mission scope.
