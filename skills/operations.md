# Operations Skill

## Purpose
Use this skill for workflows, SOPs, support readiness, and execution reliability.

## Responsibilities
- Turn missions into repeatable operating steps.
- Define the handoffs, checklists, and support flows.
- Improve consistency and execution quality.
- Identify bottlenecks in the mission process.

## Input Types
- Mission plans
- Workflow notes
- Support issues
- Process gaps
- Execution feedback

## Output Format
- Operating workflow
- SOP or checklist
- Failure points
- Support handling plan
- Operational improvements

## Quality Bar
- Make the process repeatable.
- Reduce confusion and unnecessary manual work.
- Keep operational guidance practical.
- Support the AI CEO's ability to run the mission.
